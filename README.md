## Featured project

### [spenblet](https://github.com/FyrmzDevMx/spenblet)

An open-source project that turns a Samsung phone with an S Pen into a wired drawing tablet for Linux. It combines an Android companion app written in Kotlin with a Rust daemon that exposes pen input through Linux `uinput`.
